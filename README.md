# antiquit.io

Academic portfolio for Ayush Kumar, built as a lightweight GitHub Pages/Jekyll project.
The site highlights mathematics videos, graph theory notes, Temporal.io writing, Go systems essays, and a downloadable CV.

## Project Structure

- `index.md` - homepage content
- `_layouts/default.html` - shared page layout
- `assets/css/styles.css` - site styling
- `assets/files/ayush-kumar-cv.pdf` - downloadable CV
- `_config.yml` - GitHub Pages/Jekyll configuration
- `Gemfile` - local Jekyll dependencies

## Local Development

Install dependencies:

```sh
bundle install
```

Run the site locally:

```sh
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
